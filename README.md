# আজ ভাইফোঁটা — Bengali Storytelling Website

A responsive, cinematic Bengali storytelling website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — responsive dark cinematic design
- `script.js` — scroll reveal, reading progress, share and copy-link buttons

## Run locally
Open `index.html` in a browser. For a local server, use VS Code Live Server or run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `aj-bhaiphonta-story`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your URL will look like:
   `https://YOUR-USERNAME.github.io/aj-bhaiphonta-story/`

## Before publishing
Review the story and consider replacing or removing personal names if you do not want them publicly identifiable. Anyone with the public link may be able to read the page.

The Bengali font is loaded from Google Fonts, so an internet connection is needed for that font. The page itself has no backend and collects no visitor data.
